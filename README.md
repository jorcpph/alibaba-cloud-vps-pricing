## 为什么两个“相同”的规格报价不同

相同的 vCPU，相同的 RAM，价格却接近三倍 —— 这是理解 Alibaba Cloud VPS 定价的第一个关键。实例族（名称中 `ecs.` 后面的字母）起决定性作用。`ecs.xn4.small` 是较旧的经济型系列：一项已验证的列表显示，1 vCPU / 1 GiB 的价格为每月 $15.21。新一代小型实例在相同规格下基准测试价格为 $5.62。同一个云平台，纯粹因为对比匹配的系列不同，价格就出现了近 3 倍的差距。

代际在单个系列内同样重要。`ecs.c7` 系列是当前的计算优化型产品线：一台 4 vCPU / 8 GiB 的 `ecs.c7.xlarge` 标价为每月 $89.79，而通用的“中型 VM”基准测试对相同资源报价为 $60.34 —— 追踪器没有命名该基准数据背后的具体系列。独立性能实验室测试的 `ecs.g8a.2xlarge`（8 核，32 GB，$146.11/月）则是第三种系列。

接下来是地区因素。同一个目录在乌兰察布、北京和美国东部 1 区等地区对大型实例的小时报价略有不同。这些都不是隐藏费用 —— 只是在你还没算上流量之前，“一台 Alibaba Cloud VPS 的成本是多少”就已经有了三个变量。

在购物前值得了解的一个规律：Alibaba 相对 AWS 的折扣并不均匀。小型 VM 比 AWS 便宜约 17%，大型 VM 约 14%，但在 4 vCPU / 8 GB 时差距高达 **45%**（$60.34 对比 $110.16）。定价争议最大的区间在中间地带。

## 实例价格之外的费用

实例费率仅涵盖计算资源。流量和存储是分开计费的，对于小型套餐，它们可能比服务器本身花费更多。

流量：两次独立对比均认为，超出免费额度后的 **$74 per TB** 是一致的（AWS：$90/TB）。免费额度本身则不太明确 —— 最新的对比显示为每月 200 GB，而早期版本的数据则列为 10 GB，因为额度因服务和地区而异。将 $74/TB 作为规划数字：在一个月流量繁重的 $5.62 实例上，流量费可能会超过服务器成本。

其他已验证的价格：

- 块存储：约 100 GB 的价格为 **$7.60–11.20/month**，取决于磁盘层级（Enhanced SSD PL0 位于该范围的高位）。AWS 等同产品：$8.00。
- 对象存储：1 TB 且有实际的读取/写入配额，报价为 **$27.70–43.84/month**，对比 AWS 的 $37.96。
- 负载均衡器：小型规格为 **$16.56–19.40/month**，对比 AWS 的 $22.34。
- 如果需要托管数据库：PostgreSQL 2 vCPU / 8 GB 为 $114.92/month，Redis 1 GB 高可用性为 $43.09/month。对于爱好者规模来说，两者都很昂贵 —— 大多数人在流量增加之前，直接在 VM 本身上运行数据库。

## 按量付费还是 12 个月订阅？

Alibaba Cloud 提供两种计费方式：按需（小时）和 12 个月预留。这比 AWS 少了一种选择，AWS 还提供 36 个月的预留期。如果你的计划是锁定三年的价格，目前 Alibaba 没有该期限；条款最长为一年。

实用规则：在按量付费模式下测试一到两周，确认实例族和地区符合需求，然后转为 12 个月订阅。在小型实例上，差别微乎其微，但对于 24/7 运行的任何东西，订阅依然胜出。在巨大实例上，计算显而易见：按小时 $55，按量付费仅适用于运行数小时而非数月的工作负载。

## Alibaba Cloud 定价何时合理 — 以及何时不合理

在这些情况下合理：

- 你需要中国大陆或深度的亚太地区覆盖：30 多个地区，大部分位于中国大陆和亚太地区，数据中心遍布 15 个国家（从沙特阿拉伯到韩国）。符合这一点的竞争对手名单很短。
- 你的工作负载处于中游生产范围：在 4 vCPU / 8 GB 时，45% 的 AWS 差距是整个对比中最大的。
- 你想要便宜的前几代 GPU 进行机器学习实验（A10, P100）。
- 你是一名 24 岁以下的中国学生 —— 每年 ¥9.9 无需多言。

在这些情况下不合理：

- 你的目标是微型盒子的最低月账单 —— 廉价专业主机的底价要低几倍。
- 你想要 36 个月的价格锁定；预留期限最长为 12 个月。
- 你需要前沿的 GPU（H100 及以上）。
- 你想要一家为你维护服务器的全托管主机 —— 托管型 VPS 公司将此作为产品销售，而 Alibaba 销售的是你需要自行操作的云基础设施。
